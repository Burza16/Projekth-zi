# Autónyilvántartó

A C#-os konzolprogram beolvassa és kilistázza a tíz autó adatait, majd kiírja a legdrágábbat.

- `Program (1).cs` és `IKT, asztali, adatbázis projektházi.txt` – a program és a bemeneti adatok.
- `Mysql parancsok.txt` – az `autokereskedes` MySQL-adatbázis létrehozása és az `autok` tábla feltöltése.
- `PROJEKTDOKUMENTÁCIÓ.docx` – a projekt leírása. A `szerkezeti_kép.jpeg` és a `tartalmi_kép.jpeg` a táblát mutatja phpMyAdminban.

Futtatáshoz másold a C#-kódot egy .NET konzolprojekt `Program.cs` fájljába, a bemeneti TXT-t pedig a program munkakönyvtárába.
